# Семантический анализатор

## Назначение

Модуль выполняет проход по AST после лексического и синтаксического анализа. На этом этапе проход является структурным: он посещает узлы в порядке дерева и управляет стеком областей видимости. Атомарные проверки подключаются к проходу отдельным этапом.

## Стиль кода

Код модуля сохраняет стиль существующего проекта:

- используется C++20 и иерархия классов AST с полем `NodeType`;
- конкретные классы проверок скрыты в `.cpp`-файлах;
- публичные интерфейсы описываются в заголовочных файлах;
- создание реализаций выполняется через фабричные функции `make...`;
- коллекции представлены типами `vector`, `unordered_map` и `list`;
- используется `unique_ptr` для владения узлами AST и сервисами;
- подключаются заголовки от корня проекта, например `parser/ast.h`;
- в исходниках используется `using namespace std;` на уровне файла;
- методы и параметры именуются в стиле существующего кода: `camelCase`;
- сообщения об ошибках имеют формат `Semantic error (line N): ...`;
- комментарии в исходном коде пишутся на русском языке и поясняют ограничение или решение, которое не следует непосредственно из кода.

## Структурный проход

`IAstTraversal` принимает корень `Program` и `IAstTraversalObserver`. Наблюдатель получает события `enter` и `leave` для каждого узла. Это позволяет подключить проверки без изменения алгоритма обхода.

Обход использует `switch` по `NodeType`, как и существующий AST-принтер:

- сначала посещается родительский узел;
- затем дети обходятся слева направо в порядке их хранения в AST;
- после последнего ребёнка отправляется событие выхода;
- отсутствующие `unique_ptr` пропускаются.

## Области видимости

`ScopeStack` принадлежит проходу и изменяется только в местах, соответствующих языковым конструкциям:

- `Program` создаёт глобальную область;
- `RoutineDeclaration` создаёт область параметров и локальных сущностей;
- каждый `Body` создаёт вложенную блочную область;
- `ForLoop` создаёт отдельную область времени жизни переменной цикла;
- после выхода из конструкции соответствующая область удаляется;
- вложенные `if`, `while` и тела рутин получают независимые области через `Body`.

Регистрация символов и вызов атомарных checker-сервисов остаются отдельными операциями. Это сохраняет простой проход и позволяет позже определить точный порядок: объявление, регистрация, обход и проверка использования.
